[Seed #S1] Check if a component needs 'use client' before using hooks (useState, useEffect, etc.)
[Seed #S2] Never import server-only modules in client components; use server actions for data mutations
[Seed #S3] When adding API routes, validate request body with zod or similar before processing
[Seed #S4] Do not hardcode environment variables; use process.env with proper fallbacks
[Seed #S5] When modifying database schema, always generate and review the migration before applying
[Seed #S6] Use next/image instead of raw <img> tags for automatic optimization
[Seed #S7] Check middleware.ts impact when adding new route patterns; middleware runs on every matched request
[Seed #S8] When adding new pages, verify the layout hierarchy (layout.tsx) applies correctly
